## 봉착한 문제와 해결

순서대로. 같은 문제가 다시 생기면 여기부터 본다.

### 실행 환경

| 증상 | 원인 | 해결 |
|---|---|---|
| 구독(Claude Pro·GPT Plus)으로 실험할 수 있나 | 채팅 화면은 토큰 수가 안 보이고 temperature·시스템 프롬프트를 통제할 수 없으며, 수천 회 자동 호출은 약관 위반 | API 로만 돌린다. 학교 ChatKHU(BAZE) 게이트웨이의 월 무료 한도(계정당 3,937 크레딧)를 쓴다 |
| "내 크레딧 0" | 구매 크레딧 칸을 본 것. 학교 월 한도는 따로 있음 | ChatKHU 로 확정 (D-25) |
| 홈 폴더에 데이터가 저장됨 · 예전 prepare.py 실행 | 터미널 작업 위치가 프로젝트 폴더가 아니었음 | 모든 스크립트가 시작할 때 자기 폴더로 이동하도록 수정 |
| macOS 가 .command 실행을 막음 | 인터넷에서 받은 파일 격리 표시 | `xattr -dr com.apple.quarantine .` 한 번 |
| `CERTIFICATE_VERIFY_FAILED` | python.org 파이썬 3.14 에 인증서 묶음이 없음 | `pip3 install certifi`, llm.py 가 자동으로 사용 |
| HTTP 403 `error code: 1010` | Cloudflare 가 기본 User-Agent(Python-urllib)를 봇으로 차단 | 일반 클라이언트 User-Agent 로 보냄 |

### 비용과 속도

| 증상 | 원인 | 해결 |
|---|---|---|
| 1문항 148 크레딧 (100문항이면 두 계정 한도 초과) | qwen3.8-max 만 사고 모드가 기본으로 켜져 출력 2,485 토큰 중 2,309 가 사고 | 옵션 4개를 시험해 `chat_template_kwargs.enable_thinking=false` 로 세 등급 모두 끔 → 41 크레딧 (D-27). 저가·중가도 출력의 절반이 사고였다 |
| 1문항에 5분, 100문항 9~10시간 | 호출 52개를 하나씩 순서대로 보냄 | 문항 안 호출을 동시에(D-28), 이어서 문항 여러 개를 동시에(D-30). 본실험 99문항 43분 |
| HTTP 524 (m027) | 게이트웨이가 120초 안에 끝나지 않는 응답을 끊음. 중가는 초당 약 47 토큰 | 스트리밍으로 받고 520~524 재시도 (D-32) |
| 한 답변이 20분 넘게 끝나지 않음 (m027 보충) | 반복 폭주로 추정, 길이 상한이 없었음 | `max_tokens=8192`, 잘린 답은 `finish_reason` 으로 표시 (D-36). 전체에서 1건 |
| 기록상 사용량 < 실제 사용량 | 실패·중단된 호출과 모델 시험 호출은 기록에 안 남음. gemma-3 단가는 문서에 없어 임시값 | 1번 키 기록 3,631 vs 실제 3,921 (약 8% 차이). 예산 상한을 학교 한도보다 낮게(3,700) 잡아 둔 덕에 본실험이 끝까지 돌았다 |

### 실험 설계·데이터 품질

| 증상 | 원인 | 해결 |
|---|---|---|
| D1(맥락 누락)이 9문항 중 2개만 정상 | 저가(Flash)가 만들었더니 3개는 아무것도 안 빼고 3개는 숫자 조건을 지움. 분석은 바뀌지 않은 D1 도 유효로 셈 | 고가 모델이 만들고, 다름·숫자 보존·정답 보존을 넘을 때까지 탈락 이유를 알려 주며 최대 3번. 예전 D1 은 보관 (D-29) → 유효 91% |
| m012 세 등급 모두 전부 오답 | 75명의 17% = 12.75명. 데이터 정답은 버림을 가정하지만 문제에 규칙이 없음 | 문제 결함으로 판단해 `data/excluded_items.json` 에 이유와 함께 제외 (D-31). 판단 기준은 결과가 아니라 문제 문장 |
| m016 등급과 반대로 맞힘 | 수수료를 할인 전·후 가격 중 어디에 매기는지 문장이 애매 | 정답이 정의되는 문제라 제외하지 않음. 해석이 갈리는 문항 목록은 팀이 검토할 것 |
| m009 고가 모델만 틀림 | "4분의 2 가격"을 1/4 로 읽음 | 채점 오류가 아닌 실제 오답. 그대로 둠 |
| **G1 천장 실패** (저가 기준선 97%) | Qwen 3.8 계열은 GPT-4o 보다 강해 GSM-Symbolic P1 이 너무 쉬움. 등급 차이와 결함의 대가가 대부분 드러나지 않고, Part C 에서 결함 정보의 가치가 0 또는 음수 | 선행연구 조사 + 약한 모델 5개 시험 → 저가를 gemma-3-27b 로 교체(기준선 80%, 오타에 흔들림), Plus 제외. 기존 Flash·Max 응답은 재사용 (D-33) |
| 웹 잡문(E2)이 효과 없음 | 주제와 무관한 잡음은 모델이 쉽게 무시 | GSM-NoOp 방식의 '그럴듯한 무관 정보'(N1) 축 추가 (D-35) → 고가 모델도 흔들림 |
| 오타 효과를 용량-반응으로 보고 싶음 | 5%·20% 두 점뿐 | 10% 추가 (D-34) |

## 설계가 바뀐 지점 요약

1. **v4 → v5** — 범위 축소: 개방형·심판 검증·2턴 되묻기 제거, 수학 하나로 (D-14~D-20)
2. **Qwen 3등급 → gemma / Flash / Max** — 천장 탈출 (D-33). 파일럿 Plus 응답은 기록에 보관만 하고 분석에서 뺀다
3. **결함 4축 → 5축, 변형 7 → 9** — 오타 10%, N1 추가 (D-34, D-35)
4. **원래 가설(대가는 토큰으로)** → 결과는 정답률로 나타남. 서사를 바꿔야 한다
